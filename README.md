# PAM interaktívny test

Interaktívny test z otázok PAM s režimom precvičovania, bankou otázok, filtrom tém a vyhodnotením chýb.

## Lokálne spustenie

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## GitHub Pages

Repo obsahuje workflow `.github/workflows/deploy.yml`, ktorý po pushi do vetvy `main` buildne Vite aplikáciu a publikuje priečinok `dist` cez GitHub Pages.
